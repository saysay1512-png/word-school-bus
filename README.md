# 단어 스쿨버스

미국 유치원~12학년 필수 영어 단어를 4지선다 게임으로 외우는 웹앱입니다.
단계를 고르면 단어 50개가 무작위 순서로 나오고, 틀린 단어는 맞힐 때까지 다시 나옵니다.

## 실행

- **내 컴퓨터에서 바로**: `index.html` 을 더블클릭하면 브라우저에서 열립니다.
- **설치형 앱으로**: 이 폴더를 통째로 https 주소가 있는 웹 호스팅에 올리면,
  휴대폰·PC 브라우저의 "홈 화면에 추가 / 앱 설치"로 설치할 수 있고 오프라인에서도 열립니다.
- **로컬 서버로 확인**: 이 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 접속.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 색·글꼴·배치 (밝은 화면 / 어두운 화면) |
| `words.js` | 단어 목록 (39단계, 영어=뜻) |
| `app.js` | 게임 동작, 음성 읽기, 기록 저장 |
| `sw.js` | 오프라인 저장 |
| `manifest.webmanifest`, `icons/` | 앱 이름·아이콘 |

## 고칠 때

- 단어를 바꾸려면 `words.js` 만 고치면 됩니다. 형식은 파일 맨 위 설명을 보세요.
- 파일을 고쳐 다시 올릴 때는 `sw.js` 의 `wordbus-v1` 을 `v2` 처럼 올려야 설치된 앱에 반영됩니다.
- 성공 기록(★)과 설정은 각 기기의 브라우저에만 저장됩니다.
- 음성은 기기에 들어 있는 영어 음성(Web Speech)을 씁니다. 기기에 따라 목소리가 다릅니다.
